## External implementation reference

The official TigerBeetle Go documentation requires the `github.com/tigerbeetle/tigerbeetle-go` client, Go `>=1.21`, a configured cluster ID plus replica address, and explicit account/transfer result handling. It documents `uint128` amount fields and debit/credit account constraints rather than a PostgreSQL substitute. The implementation pins `v0.17.9`, which was module-verified before local Go vet and race testing. [1]
